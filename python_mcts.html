1. Reinforcement Learning Review

1.1 Reinforcement Learning Framework

s₁, a₁, r₁
→
s₂, a₂, r₂
→
s₃, a₃, r₃
→
s₄, a₄, r₄
Core Elements:
  • s (state): Describes the current environment
  • a (action): Executable behavior
  • r (reward): Feedback after executing an action

1.2 Three Learning Methods

Value-based

  • For finite action spaces
  • Indirect decision: define value
  • Build value table: Q(s,a) → value
  • Choose action with maximum value

Policy-based

  • Directly learn policy function
  • π(s) → a
  • Map state directly to action

Actor-Critic

  • Combines value-based and policy-based
  • Actor handles action selection
  • Critic handles value evaluation

2. MCTS Theoretical Foundation

2.1 What is MCTS?

MCTS is a random simulation-based search algorithm that progressively builds a search tree through random simulation and node backpropagation, approximating optimal decisions within limited computational time.

Particularly suitable for:

  • Massive decision trees that cannot be fully expanded
  • Need to balance exploration vs exploitation
  • Game AI (e.g., Go, Chess, Tic-Tac-Toe)

2.2 Tree Structure Design

Node Structure

Node:
├── board_state      # Board state
├── player           # Current player
├── parent           # Parent node
├── children         # Child node dictionary {state_id: node}
├── visits           # Visit count
├── score            # Accumulated score
└── is_terminal      # Terminal state flag

Game Tree Example (Tic-Tac-Toe)

                    node₀ (root)
                   /  |  \  ...
                  /   |   \
              node₁ node₂ node₃ ... node₈
              /|\

3. MCTS Four Steps

1️⃣ Selection
→
2️⃣ Expansion
→
3️⃣ Simulation
→
4️⃣ Backpropagation

3.1 Selection

Goal: Select from root node to a node that is "not fully expanded"

Key Concepts:

  • Fully Expanded: All possible actions have generated corresponding child nodes
  • UCB Selection: Choose child with highest UCB score
  • Iteration: Continue until finding an unexpanded node

3.2 Expansion

Goal: Create a new child node for the selected node

Key Concepts:

  • State Generation: Generate all legal next states
  • Canonical ID: Use symmetric optimization to identify equivalent states
  • Node Creation: Build new TreeNode with parent reference
  • Track Expansion: Update is_fully_expanded flag when all states explored

3.3 Simulation/Rollout

Goal: Randomly simulate from new node until game ends

Key Concepts:

  • Random Playout: Make random legal moves until terminal state
  • Score Calculation: Win: +10, Loss: -10, Draw: 0
  • Perspective: Score from current player's perspective

3.4 Backpropagation

Goal: Propagate simulation results back to all ancestor nodes

Update Rules:

  • Increment each node's visits by 1
  • Add simulation score to each node
  • Traverse upward to root node

4. UCB (Upper Confidence Bound) Formula

UCB = sign × avg_reward + exploration_term

4.1 UCB Formula Components

Component Formula Description
sign 1 if player=='x'
-1 if player=='o'		 Adjusts score direction based on player perspective
avg_reward node.score / node.visits Exploitation: Prioritize high average score
exploration_term c × √(ln(total_visits) / node.visits) Exploration: Prioritize less visited nodes
c: exploration constant (typically √2)

4.2 UCB Balance Mechanism

Scenario avg_reward exploration_term Result
Frequently visited & high win rate High Low Medium UCB
Rarely visited ? High High UCB (Encourage exploration)
Frequently visited but low win rate Low Low Low UCB

5. Complete MCTS Algorithm

5.1 Main Algorithm Structure

MCTS Class Components:

  • search(): Main entry point, iterates selection→expansion→simulation→backpropagation
  • select(): Traverses tree using UCB until finding unexpanded node
  • expand(): Creates new child node with canonical state ID
  • rollout(): Random playout until terminal state
  • backpropagate(): Updates statistics along path to root
  • get_best_move(): Returns child with most visits or highest UCB

5.2 Symmetric Search Optimization

Key Innovation: Use canonical state representation to identify equivalent board positions

Canonical ID Generation:

  • Axis Permutations: 3! = 6 ways to permute (depth, row, col)
  • Axis Flips: 2³ = 8 combinations of flipping each axis
  • Total Symmetries: 6 × 8 = 48 equivalent orientations
  • Canonical Selection: Choose lexicographically smallest serialization
  • Performance Gain: Reduces search space by 4-8× in practice

6.3 Summary

MCTS is a powerful decision algorithm that achieves near-optimal solutions within limited time through:
  • Smart Selection (UCB)
  • Progressive Expansion (avoid full expansion)
  • Random Simulation (evaluate state value)
  • Statistical Accumulation (backpropagation)
  • Symmetric Optimization (reduce search space)
